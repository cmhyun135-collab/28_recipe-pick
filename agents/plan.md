# AI 레시피 추천 및 게시글 자동 생성 플랜

준비물: 사용자가 입력한 [사진 1~3장 (base64)] 및 [추가 요청 텍스트]

## 1. @analyst (재료 분석가)
- 작업: 입력된 시각 데이터와 텍스트를 분석하여 사용 가능한 식재료를 식별합니다.
- 출력: 식별된 재료 리스트를 생성하여 @chef에게 비공개 전달합니다.
- 전달 데이터 예시: ["계란", "양파", "스팸", "찬밥"]

## 2. @chef (레시피 셰프)
- 작업: 전달받은 재료 리스트를 바탕으로 최적의 요리 3가지를 선정하고 상세 레시피를 작성합니다.
- 출력: 제목, 재료, 조리 순서가 포함된 JSON 형식의 데이터를 @editor에게 비공개 전달합니다.
- 전달 데이터 예시: [{"title": "스팸 계란볶음밥", "ingredients": [...], "steps": [...]}, ...]

## 3. @editor (게시글 편집자)
- 작업: 전달받은 JSON 레시피 데이터를 커뮤니티 게시글 형태(Markdown)로 포맷팅합니다.
- 출력: 사용자가 바로 확인할 수 있도록 최종 결과물만 UI에 출력합니다.
- 기능: 각 레시피 카드에는 '이 레시피로 게시글 작성하기' 버튼이 포함되도록 구조화합니다.

[최종 출력 목표]
- 사용자 화면에 시각적으로 정리된 레시피 카드 3개 표시.
- 특정 카드 클릭 시 해당 데이터가 게시판 작성 폼으로 자동 바인딩.
